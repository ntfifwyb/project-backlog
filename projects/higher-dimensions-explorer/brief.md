## Summary *

An educational project about dimensions and how they work: an interactive viewport (or
similar) where the user can properly learn how 4D works, then 5D, 6D and beyond. The
user is the learner; the goal is real understanding, not just pretty pictures.

## Problem *

The user wants to understand higher dimensions (4D, 5D, 6D, "all of that") properly, and
wants an interactive way to do it rather than only reading about it. What they've tried so

## Open questions *

- [ ] **Name.** `higher-dimensions-explorer` is a placeholder Claude chose; confirm or rename.
- [ ] **Starting point.** What does the user already know (linear algebra, the tesseract,
      *Flatland*, 4D games)? What did they try that didn't make it click?
- [ ] **What "learn how it works" means.** Intuition (seeing rotations, slices, shadows),
      the math (coordinates, matrices, projections), or both?
- [ ] **Teaching style.** Free sandbox to play in, or a guided course of lessons that build
      on each other (0D → 1D → 2D → 3D → 4D by analogy)?
- [ ] **Visualization methods.** Which ones: projection (shadows), cross-sections
      (slicing, like Flatland), unfolding nets, multiple linked views, color/time as an
      extra axis?
- [ ] **Which objects.** Hypercubes only, or simplices, cross-polytopes, hyperspheres,
      user-defined shapes?
- [ ] **How high.** Is there a ceiling (6D? 10D? arbitrary n)? Past 4D, intuition gets
      thin: is the goal to see n-D generally, or to understand what changes and what doesn't?
- [ ] **Controls.** How the user rotates in planes that don't exist in 3D (xw, yw, zw...):
      sliders, mouse plus modifier keys, gamepad?
- [ ] **Platform.** Web app in the browser, desktop app, game engine (Godot), VR?
- [ ] **Other topics.** Physics or "extra dimensions" in string theory, time as a
      dimension, fractal dimension, or strictly geometry?
- [ ] **Audience.** Only the user, or something to share or publish later?
- [ ] **Success criteria.** What would show the user they've learned it? e.g. "When shown a
      4D rotation, I can predict what the 3D slice does next."
- [ ] **MVP vs Later vs Not doing.** Which of the above make the first version.
